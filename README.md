# One Line, One Laugh

Entry for the [One Line, One Laugh](https://make.fun/c/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) competition on [make.fun](https://make.fun).

`main.py` (pure Python standard library, no network, no secrets) writes one
original funny line of text to `/output/entry.txt`.

## The line

> I asked AI to write my wedding vows; it said 'I do' to the terms and conditions.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). The line is
80 characters — inside the gate of 1 to 140 UTF-8 characters.
